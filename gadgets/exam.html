Set the duration, then start your exam. Use Settings for optional rules and the completion chime.

Rules can include headings, lists, bold text, and LaTeX equations. Use $...$ or \(...\) for inline math, and $$...$$ or \[...\] for a displayed equation.

Present shows only the clock, rules, and an Exit button. Exit presentation to pause or change the timer. Restart returns to the original duration; Stop lets you set a new one.

Show in top bar is off by default. Enable it if you need to monitor the exam while browsing other pages.

Time reminder changes the background to warm amber when five minutes remain, and to a soft red when time is up. Change the reminder time or turn it off in Settings.

Keep screen awake works while the timer runs, when your browser permits it. A hidden page may pause the chime; remaining time catches up when you return.
