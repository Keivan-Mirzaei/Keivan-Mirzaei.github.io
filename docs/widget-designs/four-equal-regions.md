# Four equal regions widget design sheet

**Status:** Reviewed, approved, and published on 4 October 2026. [Live puzzle](https://keivan-mirzaei.com/puzzles/four-equal-regions/).

Follow the [widget roadmap](../widget-requirements.md). Reuse the reviewed conversation prototype's geometry and interaction, with the current shared frame, panels, saving, and progress reset rules. Page: `/puzzles/four-equal-regions/`; registry and saving ID: `four-equal-regions`.

- **Purpose:** Move and rotate two crossing lines so each of their four regions contains exactly n of 4n points. A point whose centre lies on either line remains unassigned and prevents success.
- **Appearance:** Page title supplies the name. A dominant point field, four concise counts, and a single rotation slider by default. Solid and dashed lines have no numbering or opaque handles. Region letters sit in clear space away from points. The point palette matches the count legend.
- **Interaction:** Drag a line to translate it while keeping the other line fixed. Drag the crossing to move both. Rotate with sliders. A transparent 44-pixel crossing target supports arrow keys and Shift for larger steps. Count points by their centres, not by the visible disc edges.
- **Controls:** Undo, Redo, Reset, Shuffle, Settings, Info. Omit Hint, scores, timing, and puzzle-number controls. Shuffle creates a new solvable set; there is no numbered catalogue.
- **Settings:** n uses a 1–12 slider, with 6 initially selected. Keep lines perpendicular starts on; turn it off to reveal Solid line and Dashed line rotation sliders. Free lines stay at least 12° apart. Save progress starts on and applies only to this puzzle on this device.
- **Typesetting:** Counts and angles use the interface font; simple variables in 4n and n use semantic italic notation. There are no structured formulas or scientific notation to render.
- **Goal:** When all four counts equal n and no centre is on a line, tint the field and feedback green and announce “Equal split.” Clear the effect as soon as the geometry no longer meets the goal, including after Undo or Reset.
- **History:** A completed line drag, crossing keyboard adjustment, or rotation-slider gesture is one action. Undo/Redo includes Reset, Shuffle, changes of n, and the perpendicular setting. Keep 60 compact snapshots. Cancelled drags leave state and Redo untouched; new meaningful edits clear Redo.
- **Reset / Shuffle:** Reset returns the initial line arrangement for the same points. Shuffle makes another verified solvable point set. Preserve n, perpendicular mode, and saving. Both actions are reversible.
- **Saving:** Retain each n's seed and line pose plus action history and perpendicular preference. Returning to an n resumes its own points and work. Never save panel visibility or active gestures. Disabling saving clears only this puzzle's retained state while the current game remains usable.
- **Reset progress:** In Settings, confirm with the selected n named explicitly. Reset only that n's point set and action history; retain other n sessions and history, the perpendicular and saving preferences, and other puzzles. Undo cannot resurrect the cleared progress.
- **Panels / phone:** Settings and Info start closed, toggle with their own trigger or Escape, and are mutually exclusive. Outside taps, scrolling, dragging, and slider edits keep them open. All controls and the crossing target are at least 44 pixels. The point field fits 320-pixel phones without horizontal page scrolling; transparent line hit areas make dragging easier.
- **Mathematics:** Generate deterministic, spaced point sets and verify a perpendicular solution by examining intervals between projection-order changes. Every served point set must have a checked strict equal partition, including when independent rotation is available. Keep full internal precision; use a small geometric tolerance to identify centres on lines.
- **Checks:** All n values and representative seeds, exact solutions, rotation invariance, line-boundary handling, region clipping, bounded translations, angle separation, single-line and crossing dragging, slider and keyboard action grouping, gesture cancellation, goal colour reversal, settings, Undo/Redo, reload, corrupt saves, scoped resets, panels, and phone layouts.
- **Next step:** Use this reviewed design as a reference for future geometric puzzles.
