Flip a round. Can chance leave exactly one person standing?

Each dot is a person. Filled dots are standing; outlined dots have sat down. Each round, everyone still standing makes a fresh, independent guess at a fair coin toss. Wrong guesses sit down.

The run ends with one survivor or no survivors. One survivor turns the field green. This is one simulated performance; it does not estimate the overall probability.

Undo and Redo restore the exact rounds. Reset replays this audience from the start; Shuffle begins a different run. Both can be undone. This short simulation starts fresh when you revisit the page.
